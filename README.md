# Signal Aggregator Bot

Мощная система автоматизации торговых сигналов, разработанная для высокоточного парсинга, анализа рыночных данных и автоматизированного исполнения стратегий.

## О проекте
Бот представляет собой сложный интеллектуальный комплекс, который агрегирует данные из Telegram-каналов и бирж, анализирует их в реальном времени и фильтрует по заданным рыночным паттернам.

### Основные возможности
1.  **Сложная система парсинга**:
    *   Интеграция с Bybit API для получения OHLCV-данных в реальном времени.
    *   Реализация индикатора **Waddah Attar Explosion V2** с нуля (Python), включая вычисление MACD, Bollinger Bands и адаптивной Dead Zone на базе ATR.
2.  **Многоуровневая фильтрация**:
    *   Гибкая система фильтрации сигналов: от простых уровней отрыва от индикаторов до анализа сложных паттернов из последовательности закрытых баров.
    *   Механизм дедупликации сигналов с учетом типов групп и таймфреймов, предотвращающий спам.
3.  **Техническая устойчивость**:
    *   Асинхронная архитектура на базе `asyncio`, обеспечивающая стабильную работу бота 24/7.

## Как запустить

### Требования
* Python 3.10+

### Шаги запуска
1. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка окружения**:
   Создайте файл `.env` на основе примера:
   ```env
   BOT_TOKEN=ваш_токен_бота
   API_ID=ваш_api_id
   API_HASH=ваш_api_hash
   PROXY=mtproto.example.com:443:секрет_прокси
   ```

3. **Запуск**:
   ```bash
   python main.py
   ```
