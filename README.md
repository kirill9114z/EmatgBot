# Trading Signal Aggregator & Auto-Trader Bot

Этот проект представляет собой высокопроизводительную систему для парсинга, анализа и автоматизации торговых сигналов в реальном времени. Бот является комплексным решением, объединяющим Web3-разработку, парсинг данных с криптобирж и сложную логику обработки сигналов.

## Ключевые достижения и технические особенности

### 1. Архитектура и парсинг данных
*   **Сложный парсинг**: Разработка системы парсинга в реальном времени с Bybit API для получения OHLCV данных и последующего анализа на основе индикаторов.
*   **Интеграция WAE**: Реализация индикатора **Waddah Attar Explosion V2** на Python с нуля. Алгоритм точно повторяет логику Pine Script, включая вычисление MACD, Bollinger Bands и адаптивной Dead Zone на базе ATR.
*   **Фильтрация сигналов**: Внедрение многоуровневой системы фильтрации сигналов, позволяющей отслеживать сложные рыночные паттерны (последовательности баров) и оценивать рыночную активность с высокой точностью.

### 2. Web3 и Backend-компетенции
*   **Blockchain Integration**: Глубокая интеграция с DeFi-протоколами. Разработка смарт-контрактов на Solidity (Ethereum) и Tact (TON) для реализации функций стейкинга, вестинга и управления токенами.
*   **Торговые системы**: Создание арбитражных ботов для DEX (PancakeSwap и др.) на базе Python, FastAPI, PostgreSQL и WebSocket-интеграций.
*   **Оптимизация**: Использование асинхронного стека (aiogram, Telethon, asyncio) для обработки тысяч событий параллельно без потери производительности.

### 3. Сложные задачи и надежность
*   **Network Resilience**: Преодоление блокировок Telegram в РФ путем внедрения нативной поддержки **MTProto-прокси** для работы ботов, что позволило обеспечить стабильное соединение в условиях жесткого DPI-фильтрования.
*   **Система дедупликации**: Реализация гибкого механизма дедупликации сигналов, поддерживающего различные типы торговых групп и стратегий, предотвращая спам и обеспечивая корректность исполнения сделок.
*   **Full-stack подход**: От проектирования БД (Alembic миграции) до разработки пользовательских интерфейсов и модулей безопасности (JWT-аутентификация).

## Стек технологий
* **Backend**: Python (FastAPI, Asyncio)
* **Blockchain**: Solidity, Tact (TON), Hardhat, ethers.js
* **Data**: PostgreSQL, NumPy, Pandas
* **API/Bots**: Bybit API (ccxt), Telegram API (Telethon, Aiogram)
* **DevOps**: Docker, Linux/WSL
